# User Stories

| # | Persona | User Story | Priority |
|---|---|---|---|
| US-01 | Student | As a student, I want to filter volunteering events by date and time so that I can find eco-activities that fit around my lecture schedule. | Must-have |
| US-02 | Community Leader | As a community leader, I want to create and manage an event listing so that I can organise volunteers and prepare enough equipment. | Must-have |
| US-03 | Local Resident | As a resident, I want to view an event’s location on a map and see “what to bring” instructions so that I can arrive prepared. | Must-have |
| US-04 | Eco-Activist | As an activist, I want a personal dashboard that shows my past contributions so that I can track my environmental impact. | Could-have |
| US-05 | New Volunteer | As a first-time volunteer, I want to see a welcoming description and mental well-being focus for each event so that I can feel comfortable participating. | Could-have |
| US-06 | Student | As a student, I want to quickly register for events using saved profile details so that I can avoid filling forms repeatedly. | Must-have |
| US-07 | Volunteer | As a volunteer, I want reminder notifications before an event so that I do not forget the schedule or meeting point. | Should-have |
